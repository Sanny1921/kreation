# KREATION

Website for KREATION, a web development, ads and video editing agency in Patna, India.

Mobile-first, with a 3D hero and scroll-driven motion that falls back to a lighter CSS version on slow or low-memory phones.

## Stack

React, Vite, three.js. Hosted on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`. No environment variables or secrets are needed.
