# KREATION desktop 3D

A full-screen 3D version of the KREATION site for desktop. One camera flies through four stops: Home, Services, Work, Contact. Services and Work are decks of cards that stack as you scroll.

```
npm install
npm run dev
npm run build
```

Add `?force=1` to skip the small-screen notice and the slow-GPU fail-over while testing. No environment variables or secrets are needed. The light phone site lives in the main branch.
